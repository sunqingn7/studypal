## Architecture

Tauri v2 desktop app — React 19 + TypeScript frontend, Rust backend.

```
src/
  domain/models/       # Business types (Note, Topic, File, Plugin, LLM-Pool…)
  application/store/   # 13 Zustand stores (ai-chat, file, note, settings, llm-pool…)
  application/services/# Chat routing, session, translation, classroom generation
  infrastructure/      # AI providers, plugins, file handlers, TTS, logging
  presentation/        # React views & components
src-tauri/
  src/lib.rs           # Main Tauri commands (PDF extraction, AI chat, web search, tool calling, translation)
```

- State: Zustand with automatic persistence (localStorage).
- Styling: Tailwind CSS v4 (`@tailwindcss/postcss`).
- Path alias: `@/*` → `src/*` (configured in Vite + Vitest).
- TypeScript strict mode with `noUnusedLocals` and `noUnusedParameters` enforced.

## Testing

- Vitest + happy-dom. Setup at `src/test/setup.ts` — mocks `crypto.randomUUID`, `matchMedia`, `IntersectionObserver`, `ResizeObserver`.
- Tests live alongside source as `*.test.ts` files.
- No `.tsx` test files exist yet.

## AI Provider System

All providers implement `AIProvider` interface (`src/infrastructure/ai-providers/base-provider.ts`):

| Provider | Route | Notes |
|---|---|---|
| OpenAI / vLLM / llama.cpp / Ollama / Nvidia / OpenRouter | `chat_with_openai_compatible` | `Authorization: Bearer` |
| Anthropic | `chat_with_anthropic` | `x-api-key`, `anthropic-version: 2023-06-01` |
| Gemini | `chat_with_gemini` | `x-goog-api-key`, model in URL path |

- Chat routing via `@nickname` (assigned), `@everyone`/`@all` (discuss — all providers in parallel), or no mention (auto → primary).
- Native function calling supported for OpenAI, Anthropic, OpenRouter providers. Tool schemas generated by `mcpToolToOpenAISchema()` / `mcpToolToAnthropicSchema()` in `src/infrastructure/ai-providers/tool-calling.ts`.
- Tool calls emitted via `thinking` field in `StreamChunk` events.

## Rust Backend Notes

- PDF text extraction requires `pdftotext` (poppler) or `pdf2txt.py` (pdfminer) on PATH. Fallback returns install instructions.
- Tauri commands for: PDF extraction, web search (DuckDuckGo/Tavily/Brave/Serper), AI chat (blocking + streaming + tools), TTS (Edge/Qwen), file system, translation.
- Session persistence via SQLite (`src-tauri/src/database/`).

## Plugin System

13 built-in plugins loaded at startup in `src/infrastructure/plugins/plugin-loader.ts`. Types:
- `view` — custom view components (file-browser, classroom, markdown, HTML, LaTeX)
- `file-handler` — file format support (EPUB)
- `mcp-server` — MCP tools (note, web-search, classroom, summary-skill, TTS)
- `tts-backend` — TTS engines (Edge, Qwen)

Plugins can be enabled/disabled via settings store (persisted).

## Key Files

- `src/App.tsx` — loads plugins on mount, applies theme
- `src/main.tsx` — React entrypoint
- `src/config/endpoints.ts` — all default provider/service endpoints in one place
- `src/domain/models/plugin.ts` — all plugin interface definitions
- `src/domain/models/llm-pool.ts` — LLM Pool types, persona prompts, task distribution
